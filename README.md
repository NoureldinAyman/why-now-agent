# why-now-agent

A company hiring people to do a job may soon need the tools those people use. "Why now" means a reason a company might be ready to buy at this moment, rather than at any time.

This agent reads public job ads, judges each company against a written profile, and writes a fact-checked brief for a person to approve or reject. It improves its own rules overnight and keeps a change only if its score rises on companies it has never read. It never contacts anyone.

**Status:** being built. There is nothing to run yet. See `design.md` for the design and the GitHub issues for what's being worked on.
